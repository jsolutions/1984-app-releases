# 1984 — releases

Installers and the auto-update feed for **1984**, a Windows 11 viewer for publicly published street and traffic cameras.

Download the latest `Nineteen84-win-Setup.exe` from [Releases](https://github.com/jsolutions/1984-app-releases/releases/latest). Installed copies update themselves from this feed.

The installer is not code-signed yet, so Windows SmartScreen may warn on first run ("More info" → "Run anyway").

The source code is private; this repository only hosts build outputs and pinned third-party dependencies (see the `deps-*` prereleases).
